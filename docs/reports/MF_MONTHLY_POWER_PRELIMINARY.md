## Read this with

- **A different panel from exp_004's.** exp_004's d_mf is the change in ALL mutual funds' share, from each company's shareholding filing. Here a stock-month exists only if one of the covered schemes held it — before 2019 that is ABSL, PPFAS and Motilal alone. A monthly study would ask a narrower question: what these houses' schemes did.
- **The entry date is SEBI's deadline**, the 10th of the next month, not each file's own publication time; a study would have to use the archived fetch time for months it collected live.
- **Power is not a result.** It says only whether the design could see 0.5% a month; it says nothing about whether that effect exists.
