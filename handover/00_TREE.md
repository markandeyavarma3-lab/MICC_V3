## What is NOT in this container

- **`data/`** — gitignored. Would hold the raw archive (`data/raw/archive/**`), the
  carried seed (`data/raw/v1_export`, `data/raw/v1_increments`, 2.5 GB,
  irreplaceable per decision 0027/0042), and collected parquet.
- **`db/`** — gitignored. Would hold `research_prod.duckdb` (the warehouse) and
  `governance_prod.sqlite` (the ledger).
- **`.env` / secrets** — `.gitignore` references `.env.example`, which does not
  exist in the tree (a known gap noted in AUDIT_README §16).
- **`logs/`** — gitignored, generated by `collect_daily.sh`.

Everything in this handover pack is derived from **code and documentation only**.
No live query was run against `data/` or `db/` — see `docs/DATA_INVENTORY.md`
and `docs/STATUS.md` for the most recent numbers the project generated against
its own real data (2026-09-11 and commit 472dfa8 respectively).
